PAYING SAFELY

What an agent needs to pay safely

Discover

A price list it can read before calling: a /.well-known file, a directory, a Nostr announcement.

Decide

A budget, and a check of the invoice before it pays.

Pay

A wallet with a cap it can't raise: an NWC connection with its own budget you can revoke, or a small self-custodial wallet like Wavelength.

Prove

A bearer receipt for the payment, and a separate signature when a service needs to know who is asking.

Delegate

A token it can narrow itself and hand to a sub-agent. Macaroons are built for that.

1

LESSON 1 OF 4

Share payment state, and fail closed

WHAT HAPPENED

nginx runs several worker processes, each with its own memory. A receipt used on one worker still looked unused on the next. Spent receipts now go to Redis, shared by every worker, and when Redis is unreachable the gateway refuses the payment.

TAKEAWAY

If you can't record a payment, don't accept it.

ngx-l402.org

2

LESSON 2 OF 4

Real clients bend the spec

WHAT HAPPENED

The proof of payment is a 32-byte preimage. Some custodial wallets never show it: a payment settled inside their own database leaves no preimage to hand back, so a user who paid stays locked out. Auto-detect fixed it: the gateway asks its own node whether the invoice was paid.

TAKEAWAY

Keep a way to confirm payment that doesn't rely on the client getting it right.

ngx-l402.org

3

LESSON 3 OF 4

Least access, and follow the money

WHAT HAPPENED

One gateway serves several tenants. A redemption bug paid one tenant's ecash to the default address instead of theirs. On the Lightning side, the gateway only gets a receive-only NWC connection, so a bug there can't spend anything.

TAKEAWAY

Give code that touches funds only the access it needs. Then test where the money actually lands.

ngx-l402.org

4

LESSON 4 OF 4

Host the code where it can't be switched off

WHAT HAPPENED

GitHub twice made the repository publicly inaccessible: once for a week, once for a little less. The project now lives on Nostr, pushed with ngit, and GitHub keeps a copy.

TAKEAWAY

Open payment infrastructure needs a home no single company can take down.
